数据来源与计算口径
来源
sales.csv，8 条合成的月度产品记录。
期间
2025 年 1 月与 2 月；两个完整月份。
口径
按 product 汇总 revenue；单位为美元，不混入预测值。
变化率
（37,500 − 30,000）÷ 30,000 = 25%。
净贡献
6,000 ÷ 7,500 = 80%；各产品净贡献允许为负，合计为 100%。
说明
数据展示增长来自哪些产品，未提供增长原因的证据。
查看查询详情
SELECT product,
  SUM(CASE WHEN month = '2025-01' THEN revenue ELSE 0 END) AS jan,
  SUM(CASE WHEN month = '2025-02' THEN revenue ELSE 0 END) AS feb,
  feb - jan AS delta
FROM data
WHERE month IN ('2025-01', '2025-02')
GROUP BY product
ORDER BY delta DESC;

这是示例查询，原型未连接数据源。生产版本记录实际执行语句和结果快照。
